# Dante Config Editor 2027.2.7

## Français

- Version de l'installeur Windows alignée sur l'EXE 2027.2.7 ; la recette refuse un écart avant construction.
- Source et runtime portés vers .NET 10 LTS ; Windows x64 est livré en autonome. Les nouveaux paquets Mac ciblent macOS 15 ou ultérieur et sont livrés/qualifiés séparément.
- Une récupération XML/JSON illisible est conservée avec un diagnostic et ses chemins. Copiez les fichiers, ouvrez la copie XML et enregistrez-la sous un autre nom ; rétablissez les accès si nécessaire.
- Les licences existantes, l'état local et le comportement non bloquant du rappel après l'essai sont conservés.

Windows : dans une fenêtre compacte, le libellé « Sombre » peut être tronqué. Avec navigation et inspecteur ouverts, certaines commandes de Patch/Easy Patch peuvent dépasser la zone visible. Repliez un panneau latéral ou agrandissez la fenêtre ; la matrice peut aussi être ouverte dans sa fenêtre détachée.

Les contrôles natifs Windows de capture/clavier et la matrice DPI restent non qualifiés. Le Setup a été construit et son contenu vérifié ; une mise à jour personnelle complète n'a pas été exercée pour ce lot. Voir QUALIFICATION-2027.2.7.md avant mise à jour. Conservez une sauvegarde des projets et de la banque personnelle.

## English

- Windows installer version aligned with executable 2027.2.7; the recipe rejects mismatches before packaging.
- Source and runtime migrated to .NET 10 LTS; Windows x64 is self-contained. New Mac packages target macOS 15 or later and are delivered and qualified separately.
- Unreadable XML/JSON recovery files are preserved with diagnostics and paths. Copy them, open the XML copy and save under a different name; restore file access if needed.
- Existing licensing, local state and the non-blocking post-trial reminder behavior are preserved.

Windows: in a compact window, the selected Dark theme label may be clipped in French. With navigation and inspector panels open, some Patch/Easy Patch controls can extend beyond the visible area. Collapse a side panel or enlarge the window; the matrix can also be opened in its detached window.

Native Windows screen capture, keyboard and DPI-matrix qualification remain incomplete. The Setup was built and its contents verified; a complete personal upgrade was not exercised for this delivery. Read QUALIFICATION-2027.2.7.md before updating, and retain project/personal-bank backups.

# Dante Config Editor — Windows 2027.2.9

This version clarifies the choice between free use and an optional permanent license.

- **Use for free**: choose “Continue with DCE”, without a code, purchase, or online activation.
- **Purchased or gifted permanent code**: a separate section handles activation. V2 activation requires Internet access on this computer; the activated license then works offline. Compatible legacy V1 codes remain locally verified.
- The license window scrolls while keeping Continue accessible. French and English messages also explain the case where no code has been entered.
- The policy is unchanged: 30 days without a reminder, followed by a startup reminder with a 5-second wait. All features remain available. A valid permanent license removes the reminder and wait.

The self-contained Windows installer includes .NET 10. Updates use the existing installation directory; a historical “2026.3” directory name does not identify the installed version. Check Help > About: 2027.2.9.

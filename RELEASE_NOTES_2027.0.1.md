### Ce qui change sur Windows

- Centre de connexion StageFlow LIVE accessible depuis le bandeau supérieur :
  projet local, mode autonome et session temporaire restent clairement séparés.
- Notifications de modifications visibles sur les différents écrans, avec
  ancien/nouveau label, origine et acquittement propre au poste.
- Console locale de la suite : connexion prête avant annonce de présence,
  contrôle du projet et de la session, annulation et déduplication des commandes.
- Recherche des mises à jour selon le système, avec vérification du type de
  fichier, de la taille et du SHA-256 avant installation.
- Notices Windows FR/EN, démarrages rapides et deux guides communs SiLeMI/O
  inclus dans l'installateur. Un seul raccourci Bureau : **Dante Config Editor v2027**.

Les banques personnelles, licences existantes, projets et imports/exports
historiques sont conservés. DCE reste autonome et prépare les configurations
Dante hors ligne ; StageFlow est gratuit et facultatif. LIVE synchronise le
projet, pas le matériel Dante.

**Installation :** depuis Windows 2026.10, utilisez le téléchargement direct
ci-dessus. Le repère global GitHub **Latest** reste temporairement inchangé pour
ne pas proposer un correctif Windows aux anciens clients Mac. Windows 2027.0.1
utilise ensuite la recherche de mises à jour adaptée au système.

**Contrôles :** 614 tests du moteur, 33 tests d'interface et 5 tests de licence
réussis ; installateur autonome testé avec ses six PDF et 17 captures natives
Windows. Les limites d'affichage sur petite résolution et les vérifications
restantes sont détaillées dans le
[rapport de publication](https://github.com/Mamat79/Dante-Config-Editor/blob/main/VALIDATION_2027.0.1.md).
Les fichiers Windows ne disposent pas encore d'une signature commerciale ;
les applications Mac publiques ne sont pas notariées par Apple.

### Windows changes

- A persistent StageFlow LIVE connection center keeps standalone use, local
  projects and temporary sessions clearly separate.
- Change notifications across the workspace show old/new labels, origin and
  acknowledgement status local to this computer.
- The suite's local console checks the active project and session, supports
  cancellation and deduplication, and prepares its connection before announcing presence.
- Platform-specific update discovery verifies package type, size and SHA-256.
- The installer includes FR/EN Windows guides, quick starts and both shared
  SiLeMI/O suite guides, with one **Dante Config Editor v2027** desktop shortcut.

Personal banks, existing licences, projects and historical imports/exports
are preserved. DCE remains a standalone offline Dante configuration editor;
StageFlow is free and optional. LIVE synchronises the project, not Dante hardware.

**Installation:** from Windows 2026.10, use the direct download above. GitHub's
global **Latest** marker remains unchanged temporarily so older Mac clients
are not offered a Windows-only update. Windows 2027.0.1 subsequently discovers
updates for its own platform.

**Checks:** 614 core, 33 interface and 5 licence tests passed. The self-contained
installer, six bundled PDFs and 17 native Windows captures were checked.
See the [release verification report](https://github.com/Mamat79/Dante-Config-Editor/blob/main/VALIDATION_2027.0.1.md)
for small-screen and remaining verification limits. Windows packages are not
commercially signed yet; public Mac applications are not Apple-notarised.

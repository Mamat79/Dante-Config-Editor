# Dante Config Editor 2026.6

## Licence permanente plus simple à gérer

- les licences historiques DCEP1 et DCEF1 restent valables sans conversion ;
- les nouvelles licences permettent trois activations par défaut ;
- DCE affiche le nombre d’ordinateurs utilisés et autorisés ;
- le bouton **Désactiver cet ordinateur** libère une activation ;
- après l’activation initiale, la licence reste vérifiée localement et fonctionne
  hors ligne ;
- les mises à jour conservent la licence et les fichiers utilisateur ;
- le logiciel reste entièrement utilisable après les 30 jours d’essai : seule
  la fenêtre de rappel est supprimée par la licence.

Le paiement unique de **29 € TTC** est traité par Stripe. Le code est envoyé
automatiquement après confirmation du paiement. L’auteur peut également offrir
des licences depuis son panneau privé Cloudflare, avec une limite d’activation
configurable et un historique.

## Compatibilité

- Windows 11 x64 : nouvelle version 2026.6 avec licences historiques et
  licences liées aux installations ;
- macOS : la version 2026.5 reste disponible et continue d’accepter les licences
  historiques hors ligne ;
- aucun ancien code n’est révoqué ni remplacé.

## Vérifications

- 487 tests Windows ;
- 22 tests de la base macOS ;
- 5 tests du Worker Stripe ;
- activation, réactivation, dépassement de limite, copie vers un autre compte,
  désactivation et fonctionnement hors ligne vérifiés ;
- installation silencieuse réelle et conservation des données utilisateur
  vérifiées sur Windows.

# Dante Config Editor — Windows 2027.2.9

Cette version clarifie le choix entre utilisation gratuite et licence permanente facultative.

- **Utiliser gratuitement** : choisissez « Continuer avec DCE », sans code, achat ou activation en ligne.
- **Code permanent acheté ou offert** : une section distincte permet son activation. Un code V2 nécessite Internet pour l’activation sur cet ordinateur, puis fonctionne hors ligne. Les anciens codes V1 compatibles restent vérifiés localement.
- La fenêtre de licence défile et garde la commande Continuer accessible. Les messages français et anglais expliquent également le cas où aucun code n’a été saisi.
- La politique reste inchangée : 30 jours sans rappel, puis un rappel avec attente de 5 secondes au démarrage. Toutes les fonctions restent disponibles. Une licence permanente valide supprime le rappel et l’attente.

L’installateur Windows autonome inclut le runtime .NET 10. La mise à jour utilise le dossier d’installation existant ; un ancien nom « 2026.3 » ne représente pas la version installée. Vérifiez « Aide > À propos » : 2027.2.9.

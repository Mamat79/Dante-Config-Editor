# Dante Config Editor 2027.2.7 — contrôles et limites / Checks and limits

## Français

Windows x64 autonome avec runtime .NET 10 fourni. Source exacte `257fd4594b149be4b25307d74e9539e8d0becc3a`. Installeur et programme non signés.

770 tests Windows et 51 tests du cœur Mac exécutés sous Windows réussis ; 5 tests du worker de licence et 20 contrôles de contrat de version d'installeur réussis. Les 283 fichiers du paquet ont été rehashés. La recette standard a construit le Setup ; son contenu a été extrait et comparé. Une installation ou mise à jour Windows complète du Setup standard n'a pas été effectuée pour ce lot.

Le programme commercial a été lancé dans un compte QA isolé ; les captures natives blanches/noires et le clavier restent non concluants. Les 124 rendus internes et les six contrôles dispatcher de rappel sont distincts d'une qualification native des pixels/clavier. DPI 125/150/200 %, mise à jour personnelle, raccourcis et retour arrière restent non qualifiés. Aucun XML de production, import réel dans Dante Controller ou matériel Dante n'a été testé. La compilation seule ne prouve pas la compatibilité d'un appareil.

**Limites de vue compacte examinées par le propriétaire :**

Windows : dans une fenêtre compacte, le libellé « Sombre » peut être tronqué. Avec navigation et inspecteur ouverts, certaines commandes de Patch/Easy Patch peuvent dépasser la zone visible. Repliez un panneau latéral ou agrandissez la fenêtre ; la matrice peut aussi être ouverte dans sa fenêtre détachée.

Ces observations concernent notamment la vue 1120×720 avec navigation et inspecteur ouverts. Le défilement horizontal ne remet pas à lui seul les commandes hors champ dans la zone visible. Le triage autorise la livraison avec ces réserves ; aucun correctif produit ou nouvelle compilation n'a été requis pour ces trois observations.

La gestion des licences, l'état local, les clés publiques et les codes existants sont conservés. Aucun nouveau paiement, activation ou changement d'horloge n'a été effectué pour qualifier ce paquet. Les états et clés de licence QA restent privés.

## English

Self-contained Windows x64 with the .NET 10 runtime. Exact source `257fd4594b149be4b25307d74e9539e8d0becc3a`. Installer and executable are unsigned.

770 Windows tests and 51 Mac-core tests run on Windows passed; 5 licensing-worker tests and 20 installer version-contract checks passed. All 283 packaged files were rehashed. The standard recipe built the Setup; its extracted contents were compared. A complete standard Windows Setup install or upgrade was not exercised for this delivery.

The commercial executable was launched in an isolated QA account; white/black native captures and keyboard behavior remain inconclusive. 124 internal renders and six reminder dispatcher checks are distinct from native pixel/keyboard qualification. DPI 125/150/200%, personal upgrade, shortcuts and rollback remain unqualified. No production XML, actual Dante Controller import or Dante hardware was tested. Compilation alone does not establish device compatibility.

**Compact-window limitations reviewed by the owner:**

Windows: in a compact window, the selected Dark theme label may be clipped in French. With navigation and inspector panels open, some Patch/Easy Patch controls can extend beyond the visible area. Collapse a side panel or enlarge the window; the matrix can also be opened in its detached window.

These observations concern, in particular, a 1120×720 view with both side panels open. Horizontal scrolling alone does not restore offscreen toolbar controls. The owner accepted delivery with these reservations; no product correction or rebuild was required for these three observations.

Existing licensing, local state, public keys and activation codes are preserved. No new payment, activation or clock change was performed during qualification. QA licensing states and keys remain private.
